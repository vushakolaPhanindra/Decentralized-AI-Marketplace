# Contributing to Decentralized AI Marketplace

Thank you for your interest in contributing to **Decentralized AI Marketplace**! 🚀
We welcome contributions from developers, researchers, and blockchain enthusiasts who want to improve decentralized access to AI datasets.

This document outlines the guidelines for contributing to the project.

---

## Code of Conduct

By participating in this project, you agree to maintain a respectful and collaborative environment. Please be constructive, professional, and supportive when interacting with other contributors.

---

## Ways to Contribute

You can contribute in several ways:

### 1. Reporting Bugs

If you find a bug, please open an issue and include:

* Clear description of the problem
* Steps to reproduce the issue
* Expected behavior
* Screenshots or logs (if applicable)
* Environment details (OS, Node.js version, browser, wallet)

### 2. Suggesting Features

Feature suggestions are welcome. Please open an issue and include:

* Description of the feature
* Why the feature is useful
* Possible implementation approach (optional)

Examples of possible improvements:

* Smart contract optimization
* UI/UX improvements
* Security enhancements
* Gas optimization
* Additional dataset filtering or search features

### 3. Improving Documentation

Documentation improvements are always welcome. You can help by:

* Fixing typos
* Improving clarity
* Adding examples
* Updating setup instructions

### 4. Submitting Code Changes

Follow these steps to contribute code.

## Development Setup

### 1. Fork the Repository

Click the **Fork** button on GitHub and clone your fork:

```
git clone https://github.com/your-username/Decentralized-AI-Marketplace.git
cd Decentralized-AI-Marketplace
```

### 2. Install Dependencies

```
npm install
```

### 3. Compile Smart Contracts

```
npm run compile
```

### 4. Run Tests

```
npm run test
```

### 5. Run Local Hardhat Node

```
npm run node
```

### 6. Deploy Contracts

In a new terminal:

```
npm run deploy
```

### 7. Start Development Server

```
npm run dev
```

---

## Contribution Workflow

1. Fork the repository
2. Create a new branch

```
git checkout -b feature/your-feature-name
```

3. Make your changes
4. Test your changes
5. Commit your changes

```
git commit -m "Add: brief description of your changes"
```

6. Push your branch

```
git push origin feature/your-feature-name
```

7. Open a Pull Request on GitHub

---

## Pull Request Guidelines

Before submitting a pull request, please ensure:

* Code compiles successfully
* All tests pass
* No unnecessary files are included
* Smart contracts are secure and optimized
* Code follows consistent formatting
* Clear description of the changes is provided

---

## Smart Contract Contribution Guidelines

When modifying Solidity contracts:

* Ensure proper input validation
* Avoid reentrancy vulnerabilities
* Optimize gas usage
* Add tests for new functionality
* Document important functions

Security is critical for blockchain applications, so please review contracts carefully.
